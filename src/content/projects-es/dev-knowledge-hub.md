**Dev Knowledge Hub** es una plataforma para recopilar, organizar, buscar y compartir recursos técnicos. Ofrece una aplicación web multilingüe, widgets integrables y una extensión de Chrome que captura la página activa y prepara un borrador analizado del recurso.

## Una Plataforma de Conocimiento para Desarrolladores

Construí el producto con **Next.js**, React, TypeScript, Tailwind CSS, Bun y **Supabase**. Su capa de datos utiliza esquemas declarativos, migraciones, pruebas pgTAP, seguridad a nivel de fila y roles de organización para mantener el conocimiento compartido separado y protegido.

La plataforma también expone recursos autenticados mediante el **Model Context Protocol** para clientes MCP y ChatGPT. Su flujo OAuth 2.1 usa PKCE, metadatos de recursos protegidos, vinculación de audiencia y clientes permitidos, haciendo posible que las herramientas de IA consulten el conocimiento sin debilitar la autorización.

## Resultado

Dev Knowledge Hub conecta la captura desde el navegador, el conocimiento estructurado de los equipos y la recuperación mediante IA, reduciendo la fricción entre descubrir un recurso útil y volver a encontrarlo más adelante.
