**Python Template** es un generador basado en Copier para bibliotecas, CLIs, APIs, agentes de IA, sistemas RAG, espacios de entrenamiento, servicios de inferencia y otras cargas de trabajo en Python.

## Componible por Diseño

Los usuarios pueden comenzar con un preset definido o seleccionar componentes compatibles por capas, incluyendo frameworks, interfaces, proveedores de modelos, sistemas de datos, autenticación, despliegue e infraestructura como código.

Diseñé los proyectos generados para incluir una estructura tipada, dependencias bloqueadas con **uv**, pruebas, linting, CI, automatización de seguridad y artefactos opcionales de documentación y despliegue. La plantilla prueba combinaciones renderizadas y conserva las respuestas de Copier para permitir futuras actualizaciones.

## Resultado

Python Template convierte la configuración repetitiva de herramientas de producción en una base probada y actualizable, permitiendo al mismo tiempo que cada stack generado se adapte a su caso de uso real.
